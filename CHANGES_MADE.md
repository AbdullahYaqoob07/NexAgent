## 🔧 Files Modified

### 1. Python Orchestrator

**File:** `lib/workflow/langgraph/orchestrator.py`

**What changed:**

**BEFORE:**
```python
def _register_node_types(self):
    """Register all 20 nodes from src/workflows"""
    from .nodes import (
        # 15+ imports
        ScheduleTriggerExecutor,
        WebhookTriggerExecutor,
        # ... all nodes listed manually
    )
    
    # Manual registration
    self.executor_factory.register_executor("Schedule", ScheduleTriggerExecutor)
    self.executor_factory.register_executor("Scheduling", ScheduleTriggerExecutor)
    # ... repeated 50+ times for all aliases
```

**AFTER:**
```python
def _register_node_types(self):
    """
    Auto-register node types from shared/nodes-metadata.json
    
    This eliminates manual type+alias registration. Each node's metadata
    declares its executor and aliases.
    """
    import json
    import importlib
    
    # Load nodes metadata (generated by build script)
    metadata_path = Path(__file__).parent.parent.parent.parent / 'shared' / 'nodes-metadata.json'
    
    with open(metadata_path, 'r') as f:
        metadata = json.load(f)
    
    registered_count = 0
    for node_meta in metadata.get('nodes', []):
        # Dynamically import and register
        executor_class = self._load_executor_class(node_meta.get('executor'))
        self.executor_factory.register_executor(node_meta.get('type'), executor_class)
        
        # Register all aliases
        for alias in node_meta.get('aliases', []):
            self.executor_factory.register_executor(alias, executor_class)
        
        registered_count += 1
```

**Key improvements:**
- ✅ No hardcoded imports
- ✅ No manual registration list
- ✅ Scales to unlimited nodes
- ✅ Single source of truth (JSON)
- ✅ Added `_load_executor_class()` helper
- ✅ Added `_register_node_types_legacy()` fallback

**Lines changed:** ~150 (replacement + additions)

**Backward compatibility:** ✅ Yes (includes legacy fallback)
